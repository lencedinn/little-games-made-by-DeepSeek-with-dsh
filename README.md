# 两个小游戏 · Two Little Games

全部由 **DeepSeek Harness 里的 AI 从零写完**：单文件 HTML，无框架、无第三方库、无外部素材。
美术是 Canvas 实时绘制，音乐和音效是 WebAudio 实时合成——仓库里除了 HTML 没有任何资源文件。

| 游戏 | 类型 | 一局时长 |
|---|---|---|
| [霓虹闪避 NEON DODGE](neon-dodge/index.html) | 实时 · 躲避 + 擦身连击 | 40 秒 ~ 2 分钟 |
| [光路 LUMEN](lumen/index.html) | 回合制 · 光路解谜 | 每关 30 秒 ~ 3 分钟 |

**运行方式**：双击 `index.html`，或丢进任意静态服务器。不需要构建、不需要联网。

## 1. 霓虹闪避 · NEON DODGE

`neon-dodge/index.html` · 82 KB

俯视视角的霓虹街机。方块从上方砸下来，你要贴着它们擦过去——**擦身**会累积连击倍率，连击 3.4 秒不续就会断。

- **移动**：鼠标 / 手指拖动（飞船固定在下方一条窄带内，横向 1:1 跟手）
- **冲刺**：空格 / 手机 DASH 键。冲刺期间无敌，撞碎方块得分
- **擦身**：从方块边缘擦过，连击 +1，倍率最高 x3
- **掉落**：绿球加分、金球大分、粉球补护盾、蓝球慢动作

内容：

- 3 种飞船（平衡 / 疾影 / 壁垒）× 3 档难度（休闲 / 标准 / 狂潮）
- 每 3 波一个**精英**，两种随机出现：
  - **守卫**：悬停射击 → 预警 → 砸地 → 横扫，冲刺撞它才掉血
  - **巡猎者**：贴着你的高度高速横穿，沿途撒下延迟爆开的残影弹
- 精英半血会**暴走**：节奏加快、弹幕变密、配色转红
- 6 个成就、本机排行榜、每局结算评级（C/B/A/S）

快捷键：`P` 暂停 · `M` 静音 · `S` 开关震动 · `F` 帧率 · `L` 性能模式 · `Enter` 全屏

## 2. 光路 · LUMEN

`lumen/index.html` · 51 KB

回合制解谜。转动镜面，把光从光源送到核心——**没有时间压力，也没有失败**，只有步数。

- **点击镜面**旋转 45°，光束实时跟着重画
- 目标：点亮**全部**核心
- 每关有 **PAR**（最优步数，穷举所有朝向得出的精确值），`≤PAR` 三星
- `Z` 撤销 · `R` 重开本关 · `H` 提示 · `Esc` 关闭面板

元素（按关卡解锁）：

| 元素 | 作用 | 起始 |
|---|---|---|
| 镜面 | 90° 反射 | 1 |
| 分光镜 | 直行 + 90° 分出一束 | 6 |
| 传送门 | 光从一端进、另一端同向出 | 9 |
| 上锁镜面 | 不能转，只能绕 | 12 |
| 双核心 | 必须同时点亮 | 6 |

关卡：

- **3 关手写引导**：第 5 / 8 / 11 关，每关 1 步，专教一个新元素
- **无限程序生成**：棋盘封顶 12×8，元素按关卡号解锁，难度阶梯（前段 par 2，后段 4~6）
- **每日一关**：用日期做随机种子，当天全世界是同一道题，通关后可一键复制成绩

每关生成后都会做一次**自检**：把可转镜子的 2ⁿ 种朝向全跑一遍，确认有解，并算出精确 PAR。

## 技术说明

- **单文件**：每个游戏就是一个 HTML，样式、逻辑、美术、音频全在里面
- **零依赖**：没有打包工具、没有 CDN、没有字体文件
- **音频**：WebAudio 手写合成器（底鼓 / 踩镲 / 贝斯 / 琶音 / 卷积混响），没有任何音频文件
- **存档**：`localStorage`
- **确定性**：解谜关卡的生成用可播种随机（mulberry32），所以每日关可复现

## 开发过程中的验证

两个游戏都不是“写完就交”——核心逻辑用 Node 跑真实脚本验证过（用最小的 DOM/Canvas 桩）：

- 霓虹闪避：约 5000 帧的冒烟测试，覆盖开局、冲刺、暂停、死亡、结算、重开
- 光路：100 关全量审计——独立穷举复核 PAR、检查镜面朝向与光束计算是否同步、按最优解实际点一遍确认能通关
